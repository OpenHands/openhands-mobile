# OpenHands Mobile

Phone and tablet client for OpenHands (iOS and Android).

This repository is in the planning stage. There is no app binary yet.

- Product and architecture notes: [`docs/PLAN.md`](docs/PLAN.md)
- Intended stack: Expo (React Native), one TypeScript codebase
- Sibling desktop UI: [`OpenHands/OpenHands`](https://github.com/OpenHands/OpenHands) (Agent Canvas)

## Status

Planning only. Do not treat this as a published app or a stable API.
